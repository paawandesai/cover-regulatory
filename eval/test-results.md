CI (GitLab) runs the secrets scan, lint, type checks, a production build, the unit tests, the frontend tests, the browser tests and the Terraform checks on every push, and publishes JUnit reports. The `db-tests` job also runs the golden, API and adversarial suites on every push: it restores the latest database dump from the project's private package registry (the dump holds hand-saved regulation text, so it stays out of git) into a throwaway Postgres with PostGIS and pgvector, and fails rather than skips if the database is missing. The `e2e` job runs the browser tests in Playwright's Chromium image; their API answers are recorded from the local database by `scripts/e2e-fixtures.py`, with regulation chunks cut down to the quotes the assessment cites.

Retrieval quality and latency are reported in the README (Measured results), `eval/retrieval/results.md` and `eval/latency.md`.
