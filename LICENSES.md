# Licenses

Dependency licenses are regenerated with `scripts/license-audit.sh` (pip-licenses for the backend,
license-checker for the frontend). Last run 2026-10-17. Nothing enforces a run before each push; re-run before submission.

## Policy
No AGPL/GPL libraries linked into the app (GPL servers run as separate processes are fine), nothing
non-commercial or research-only, nothing archived or with open critical CVEs.
