# Licenses

Dependency licenses are regenerated with `scripts/license-audit.sh` (pip-licenses for the backend,
license-checker for the frontend) before each push and before submission.

## Policy
No AGPL/GPL libraries linked into the app (GPL servers run as separate processes are fine), nothing
non-commercial or research-only, nothing archived or with open critical CVEs.

## Notes on specific licenses
| Package | License | Why it is acceptable |
|---|---|---|
| psycopg, psycopg-binary | LGPL-3.0 | Used unmodified as a dynamically loaded library; LGPL permits this in proprietary apps |
| certifi | MPL-2.0 | File-level copyleft only; used unmodified |
| PostgreSQL | PostgreSQL License | Separate server process |
| PostGIS | GPL-2.0 | Separate server process (database extension), not linked into the app |
| pgvector | PostgreSQL License | Database extension |
